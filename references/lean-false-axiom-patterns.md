# Lean 假公理审计模式（2026-08-19 CGICE V9.1 终审实录）

对论文 + Lean 形式化证明做"数学推导完备性终审"时，除已有的「可证 False（爆炸原理）/ 表演性诚实 / :=True 空壳」模式外，还须查这四类假公理/零内容公理。每类都给出了确凿的检测方法和删除影响评估。

## 模式 1：假命题全称量化公理（可证 False）

```lean
axiom spec_gap_bound : ∀ (grad_sq lapV : ℝ), 0 ≤ grad_sq - lapV
```

声称"对所有实数 grad_sq、lapV，恒有 grad_sq − lapV ≥ 0"。**这是假命题**：取 grad_sq=0、lapV=1 得 `0 ≤ -1`，Lean 可证 `¬(0 ≤ -1)`，于是该公理 + 反例 → False，爆炸原理。

**根因**：作者把"对特定函数 V_eff 成立的条件"（如半经典势阱条件 |∇V|² − hΔV ≥ 0）误写成"对一切实数对成立"的全称量化。原意是对的，量化范围写错了。

**检测**：扫描所有 `axiom ... ∀ ...` 全称量化声明，逐个代入反例测试。任何形如 `∀ x y, 0 ≤ f(x) - g(y)` 或 `∀ x, P(x)`（P 含自由变量 x 且不是恒真）都要警惕。

**修复**：量化范围改为绑定到具体函数的算子（`∀ χ, 0 ≤ grad_sq_of χ - lapV_of χ`），或删除该公理（若论文不依赖它做推导）。

## 模式 2：零内容公理（1×1=1 命名深刻定理）

```lean
axiom a23_bochner_horizontal_laplacian : (1 : ℝ) * (1 : ℝ) = (1 : ℝ)  -- 1×1=1
axiom a24_stratonovich_sde_solver : (1 : ℝ) = (1 : ℝ)                  -- 1=1
```

内容是平凡恒等式（1×1=1、1=1），却命名为深刻定理（"Bochner 水平拉普拉斯等价""Stratonovich SDE 存在唯一性"）。这是**表演性声明**——用平凡事实冒充"已形式化的深刻结果"，用来凑 axiom 数量让 Lean 文件"看起来形式化完整"。

**检测**：扫描 `axiom ... : (1:ℝ)*(1:ℝ) = (1:ℝ)` 或 `: (1:ℝ) = (1:ℝ)` 这类平凡恒等式。凡是 axiom 内容能被 `norm_num`/`rfl` 直接证明的，都是零内容。

**修复**：删除，改为诚实注释（"该定理是研究级前提，Mathlib 未形式化，引用文献 Elworthy 1982 / Emery 1989"）。

## 模式 3：量级对但精确值错的假实数等式公理

```lean
axiom covariance_dissipation_value : covariance_dissipation 35 tau_c = (10 : ℝ) ^ (-(122 : ℤ))
-- 即 exp(-2×35×4.01) = 10⁻¹²²
```

独立精确计算：exp(-280.7) = **1.2403×10⁻¹²²** ≠ 1.0×10⁻¹²²（差 1.24 倍）。量级对了（都是 10⁻¹²²），但精确值不等。

**比上一轮"差 101 量级"更隐蔽**：量级对让作者和 LLM 审稿人都容易放过，但 Lean 的 `Real.exp` 是精确实数，`norm_num` 对 `Real.exp` 透明性不足，无法察觉 exp 等式为假。本质仍是"把近似关系 ≈ 偷换成精确等式 ="。

**检测**：对所有含 `Real.exp` / `Real.sqrt` / 超越函数的 axiom 等式，用 Python 精确计算（`math.exp`、`math.sqrt`）比对精确值，而非只看量级。

**修复**：改为区间断言（`0 < e^{-280.7} ∧ e^{-280.7} < 2e-122`，可证真命题），或让参数由等式定义（`tau_c := 122*ln10/(2*35)`），或删除（若只是数值计算，本就不需公理）。

## 模式 4：孤立公理删除评估（grep 零引用）

终审常需回答"删除这条假公理对论文论证逻辑是否有影响"。用 grep 检查公理的引用次数：

```bash
grep -n "公理名" proof.lean
```

**判定规则**：
- 若公理**只出现 1 次**（仅定义处，零引用）→ 它是"孤立公理"，删除**不影响编译**、不影响其余定理/引理的证明。
- 若被后续定理 `exact 公理名` 引用 → 删除会破坏编译，需先评估依赖链。

**关键洞察**：假公理/零内容公理几乎总是"孤立的"（因为它们是凑数的，从未真正参与任何证明）。删除后论文的"论证逻辑"完全不受影响——因为：
- 假命题公理（模式 1）数学上只能导致爆炸原理，**不可能**支撑任何正确结论；
- 零内容公理（模式 2）无任何论证内容；
- 假实数等式（模式 3）是精确值错，论文正文的近似计算（≈1.2×10⁻¹²²）反而是对的。

**删除后的真正影响是"诚实性暴露"**：暴露论文声称的"形式化证明"实际没有覆盖几个关键论述（谱隙严格证明、122 解码、EEM 构造），这些论述的"形式化支撑"本就是假的或空的。删除是**正确的**，但须在论文里诚实标注这些"未形式化"的部分。

**完整判定流程**：
1. `grep -cE '^\s*axiom '` 统计 axiom 总数（排除注释行）
2. `grep -n "公理名"` 确认每条可疑公理的引用次数
3. 对零引用公理：删除 + 补诚实声明注释（"研究级前提，未形式化，文献引用"）
4. 删除后复核：axiom 数、begin/end 结构、active sorry（排除注释里的 "0 sorry" 字样——`grep -vE '^\s*--'` 不排除 `/--` 文档注释，需额外过滤）
