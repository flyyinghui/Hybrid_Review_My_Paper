# 审稿人算术假阳性：单位转换 + 前置因子漏检（V19 终审 2026-09-21 实测）

5 代理终审中，technical-reviewer 和 consistency-checker 报告了两类"数值矛盾"，经独立重算均为**假阳性**。这两类是物理论文审稿的高频陷阱，比"约定错误"（T_F index、归一化）更隐蔽。

## 案例 1：ℏ 单位转换漏检（自然单位 → 物理单位）

**审稿人声称**：论文 §9.3 的 f₀ = 2.65×10⁻⁸ (T_*/GeV) Hz，但按公式代入得 1.744×10⁻³²·T_*，**差 10²⁴ 个数量级**，判 P1 算术错误。两个审稿人（technical + consistency）独立得出相同结论。

**独立重算真相**：论文正确。审稿人算的是**自然单位**下的频率（GeV），漏了论文明确写的 ℏ 转换（"Converting the natural-unit frequency with ℏ=6.582119569×10⁻²⁵ GeV s"）：

```
1 GeV = 1/ℏ Hz = 1/(6.582×10⁻²⁵) Hz = 1.519×10²⁴ Hz
1.744×10⁻³² GeV × 1.519×10²⁴ Hz/GeV = 2.65×10⁻⁸ Hz  ✓ 与论文一致
```

**识别信号**：审稿人报"差 N 个数量级"（尤其 10²⁴ = ℏ⁻¹、10⁸ = c、10¹⁰ = hc 等物理常数），先检查是否涉及**单位制转换**。物理论文摘要/公式里常给自然单位值，正文另给物理单位值，两者量纲不同，审稿人直接比较即假阳性。

## 案例 2：前置因子 1/2 漏检

**审稿人声称**：§2.2 表"RG fixed-point square = 12π²/35"与 §8.1 的 β 函数不自洽，应为 24π²/35，导致"ratio two"代数结论失效。

**独立重算真相**：论文正确。β(g) = ηg/2 + bg³/(8π²)，不动点 β(g*)=0：

```
η·g*/2 + b·g*³/(8π²) = 0  →  η/2 + b·g*²/(8π²) = 0  →  g*² = -η/2 · 8π²/b = -η·4π²/b
η=-36/35, b=12: g*² = (36/35)·4π²/12 = 12π²/35  ✓
```

审稿人漏了 ηg/2 里的 **1/2 因子**，用了 g*² = -η·8π²/b = 24π²/35（错误）。而另一个代理（consistency-checker）独立算出 12π²/35（正确），两个代理互相矛盾——**同案两代理结论分歧时，独立重算仲裁，不盲信任一方**。

**识别信号**：审稿人报"不动点/系数/比值与公式不自洽"时，先完整重推一遍（别跳步），重点核对 1/2、4π、2π、n! 等易漏前置因子。

## 通用检测规则

审稿人报"数值矛盾 / 差 N 个数量级 / 与公式不自洽"时，**在转达为 P0/P1 前必须独立重算**，并依次排查：

1. **单位制转换**：ℏ（GeV↔Hz，1/ℏ≈1.519×10²⁴）、c、k_B、hc 等。自然单位值 vs 物理单位值直接比较 = 假阳性。
2. **前置因子**：1/2、4π、2π、n!、√ 等。审稿人跳步推导易漏。
3. **约定依赖**：T_F index、Killing 归一化、Dirac/Weyl 费米子 4/3 vs 2/3 系数。
4. **多代理共识 ≠ 正确**：两个代理独立报同一"矛盾"仍可能是假阳性（本次两个代理都漏了 ℏ）。

独立重算用 Python `math`/`mpmath` 精确值，不依赖审稿人给的中间值。详见 `reviewer-arithmetic-false-positive-verification.md`（T_F index、b₀=12 等约定类案例）。
