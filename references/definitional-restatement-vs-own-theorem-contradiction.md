# Definitional Restatement Contradicting the Paper's Own Theorem

## 模式（Pattern）

论文声称「从结构 X 导出量 Q」，但 Q 的推导链实际是：

1. 定理 A（真实）：某个中间量 M 成立（可证）。
2. **定义步骤**（非推导）：`Q := f(M)`，其中 `f` 引入一个「选择」——divisor、归一化、equipartition 因子等。
3. 算术：Q 的数值由此机械得出。

**致命信号**：论文自家另一个定理 B 恰恰证明了步骤 2 的选择是「任意的」（例如 Prop.1 证明「r∥/r⊥ = d 对任意 d 成立」），而 Q 的声称却把该选择当作「被迫的 / 导出的」。此时定理 A/B 与 Q 的声称**逻辑矛盾**：一个说「选择任意」，另一个说「选择被迫」。

## 检测清单（Detection checklist）

审稿 / 修订时，对每个「导出 X」的声称逐条问：

1. X 的推导链是否含一个**定义步骤**（`X := 含自由参数的表达式`）？
2. 该自由参数是否被贴上「结构标签」（如 `rank(A₃)`、`dim`、`|ρ|²`）以显得「被迫」？
3. 论文自家是否在别处**证明了该参数是任意选择**（如「对任意 divisor d 成立」「任意归一化约定」）？
4. 若是 → 这是**定义性重述 + 自相矛盾**。X 的声称应从 `[T]`（定理）降级为 `[M]`（匹配输入）或 `[O]`（开放桥）。

## 案例（Case study）：光速分界面论文第三轮终审

声称：`c² = λ∥/λ⊥ = 3` 是「从谱结构导出的光谱光速」（公式 F6 标 `[T]`）。

推导链：
1. `λ∥ = |ρ|² = 35`（`[T]` 真定理）。
2. `λ⊥ = λ∥/rank(A₃) = 35/3`（**定义，非推导**——只是把 divisor 标上「rank(A₃)」的标签）。
3. `c² = λ∥/λ⊥ = 3`（算术恒等式）。

致命矛盾：论文自家 **Prop.1 证明「r∥/r⊥ = d 对任意 d 成立」**（比值任意选择），与「c²=3 是导出的」逻辑矛盾。5 位审稿人一致判定 **P0**：`definitional restatement dressed as a derivation`。F6 的 `[T]` 标签应为 `[M]`/`[O]`。

## 出路（Two escape routes）

1. **诚实降级**（推荐，符合诚实纪律）：把声称从 `[T]` 降为 `[M]`/`[O]`，明确声明「该量是约定/选择，非导出」。
2. **证明参数是被迫的**（更难）：引入额外对称性（如 SO(3) 空间各向同性）使 divisor 从「任意」变「被迫」。但会引入**新的 `[M]` 输入**，仍可能是条件构造——审稿人大概率仍判 PARTIAL，只是把矛盾从「任意 divisor」转移到「SO(3) 对称假设」。

## 与相邻模式的关系

- 不同于 `parameterization-disguised-as-dynamical-closure`（参数伪装成动力学）：这里是**定义伪装成推导 + 与自家定理自相矛盾**。
- 是 `honesty-downgrade-paradox` 的具体机制之一：诚实化降级会暴露这类矛盾，评分反而回落。
- 与 `existence-proof-reverse-engineering-detection`（反向工程凑数）同族：都涉及「把选择伪装成推导」。
