2026-09-11 V17 三大时空相论文投稿前清理实录。终审（3.3/10）定位 6 个 P0 后，清理层全部落地，
内容级 P0 修订（装饰器/占位类型/开放命题/归一化混用）另做。

## 一、历史版本残留清除（md 文件）

### 识别模式（grep 统计）
| 残留类型 | 正则 | 处理 |
|---------|------|------|
| 内联修正标记 | `\[V\d+\s+[^\]]*correction[^\]]*\]` | 删除标记，保留前后正确内容 |
| 撤回叙事 | `WITHDRAWN`（大写） | 精简为"当前状态陈述" |
| 审查记录段落 | `【2026-\d{2}-\d{2}...】...` | 整段删除 |
| 日期戳 | `\[2026-\d{2}-\d{2}[^\]]*\]` | 删除 |
| 框架对齐标记 | `\[FRAMEWORK ALIGNMENT[^\]]*\]` | 删除 |
| 引用别稿 | `\[V63 §[^\]]*\]` | 改为中性文字 `(cf. the companion paper)` |

### 关键陷阱
1. **小写 "withdrawn" 是正常诚实声明**（如 "are **P** (or withdrawn)"、"are withdrawn"），
   与大写 `WITHDRAWN` 撤回叙事不同，**必须保留**。判定：大小写敏感 + 看上下文。
2. **"FIX" 大多是普通单词**（fixed point / fixed normalization），`grep -oiE "[a-z]*fix[a-z]*"`
   确认后再决定是否处理。
3. **清理正则非贪婪匹配会误删附录**：删除 `【2026...】` 段落的正则
   `\n*【2026-...】[^\n]*(?:\n[^\n]*)*?(?=\n\n|$)` 可能跨越附录标题（`# *APPENDIX A*` 前无空行）
   把整个附录吞掉。**必须备份 + 每次清理后验证附录标题存在**（`grep "APPENDIX A"`）。
   误删后从 `_bak_cleanup` 提取 `# *APPENDIX A` 到文件末尾恢复，再对附录单独做同样的清理。

### WITHDRAWN 叙事 → 当前状态陈述的改写模式
- `X is WITHDRAWN: Y`（Y 是正确结论）→ 直接陈述 Y，删 "X is WITHDRAWN" 前缀
- 纯撤回叙事（无正确结论）→ 整句删除
- 表格里的 `... WITHDRAWN (Vxx correction)` 行 → 整行删除（跨行时用 `[^\n]*WITHDRAWN[^\n]*\n` 单行正则会漏，需 `re.S` 多行）

## 二、参考文献重建

### 检测三类问题
1. **范围引用展开**：`[1--5]` 必须展开为 {1,2,3,4,5}，不能只取端点。
   解析 `re.match(r'^(\d+)\s*-\s*-?\s*(\d+)$')` 后 `range(a, b+1)`（限制 `b-a<=10` 防误判）。
2. **幻影引用**：正文用 `[N]` 但 REFERENCES 无。**注意 `[100]` 可能是数学区间**
   `κ ∈ [10, 100]`，非引用编号——用 `grep` 看上下文确认。
3. **孤儿引用**：REFERENCES 有但正文完全没引用（编号 or 作者名都没出现）。

### 作者名引用补编号
正文用作者名引用（Atiyah–Singer、Seeley–DeWitt、Brascamp–Lieb、DESI、Mersini 等）但无
`[N]` 编号的，在**首次实质出现**处补编号。注意：
- 摘要关键词里的作者名（"Atiyah-Singer index theorem" 在 Keywords）不是引用位置，跳过
- 跨行匹配（"Brascamp-Lieb\ninequality" 是 `\n` 非空格）——先 grep 实际字符再替换
- `GEODESICS` 含子串 "DESI"（GEO-DESI-CS）——作者名正则匹配要小心子串误匹配

### 重编号
删除孤儿 → 按原顺序连续重编号（旧→新映射 dict）→ 正文 `[N]`/`[N,M]`/`[N--M]` 全部按映射替换。
替换函数只处理**纯数字引用**（`re.match(r'^[\d,\-\s]+$')`），数学公式不受影响。

## 三、公理计数统一

论文附录常有多重矛盾口径（V17 实测：65/42/46、65/36、108/43、402/429/32/96、185/50/8/21
提案）。统一方法：
1. 独立实测（剥嵌套块注释后统计 axiom/theorem/lemma/def/opaque）
2. 定位所有计数声明（grep `axiom|theorem|lemma` 附近的数字）
3. 整段替换为一句实测声明，删除所有历史口径 + RE-CLASSIFICATION 提案表 + 双口径对照

实测口径（V17）：**62 axiom + 48 theorem + 18 lemma + 40 def + 10 opaque**，0 sorry/admit/`:=True`。

## 四、关键公式编号（纯文本 md）

纯文本 md 的公式识别（非 LaTeX `$$`/`\[` 环境）：
- 独立成行 + 含数学符号（`∇∂∫Σλρ≤≥→∈` 等）+ 含 `=` + 不含英文停用词（is/the/which/where/are/not）
- 从候选里人工筛出"真正独立的显示公式"（~14 个），按行号在行尾加 `(N)` 编号
- 多行公式编号加在最后一行

## 五、lean 注释清理

lean 文件 94% 是注释（历史版本记录）。清理：删除含版本标记（`[V4Flash`/`[FIX`/`[2026-`/`[L0x`）
的**整行注释**，块注释内的标记用 `re.sub(m, '', lean)` 替换为空。
**验证活跃代码完整**：清理后重跑剥注释统计，axiom/theorem/lemma/def/opaque 数必须不变，
sorry/admit/`:=True` 仍为 0。检查 `/-` 与 `-/` 配平。

## 六、执行陷阱

1. **heredoc 里 Unicode 特殊字符（λ、∥、²、→）导致 terminal 超时/报错**——改用
   `write_file` 写 Python 脚本再 `python script.py` 运行，避免 heredoc 转义问题。
2. **f-string 不能含反斜杠**（`f"\{x}"` 报 SyntaxError）——正则里的 `\d`/`\\` 要
   移到变量或普通字符串。
3. 每次批量替换后立即 `grep` 验证目标残留计数归零 + 文件结构完整（标题/附录/REFERENCES 存在）。
