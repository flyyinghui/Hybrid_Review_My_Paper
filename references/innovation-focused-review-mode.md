# Innovation-Focused Review Mode (V57, 2026-07-23)

## Trigger

User asks "从创新性角度" / "innovation assessment" / "比较学术创新性工作" — triggers a review that SEPARATES innovation scoring from correctness scoring.

## 6-Reviewer Panel

| Reviewer | Focus | Output |
|:--|:--|:--|
| EIC | Overall innovation + venue | innovation_score, most_innovative_element, least_innovative_element |
| R1 Neutrino | Benchmark vs 5 leading neutrino models 2023-2026 | Percentile ranking, gap analysis |
| R2 Cosmology | Benchmark vs cosmological M_R predictions | Innovation originality rating |
| R3 Formal | Benchmark vs formal verification projects (Scholze, Tao, AlphaProof) | Methodological novelty |
| DA Devil | Identify overclaimed innovations | Genuine vs repackaged vs unsubstantiated classification |
| R5 Benchmark | Cross-disciplinary percentile ranking | Top-3 papers per subfield, V57 percentile |

## Key Difference from Standard Review

- **innovation_score** (1-10) rates conceptual novelty, NOT correctness
- **percentile_rank** places the work among top papers, not against an absolute standard
- Verdict can be MAJOR_REVISION even with low correctness if innovation is high
- The split between innovation (5.2) and correctness (3.4) is itself diagnostic
