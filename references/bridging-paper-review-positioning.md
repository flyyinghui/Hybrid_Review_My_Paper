# 衔接论文（bridging paper）vs 独立理论的审稿定位

## 核心教训（2026-10-14 中微子 V65 三论文审稿验证）

**审稿前必须先确认论文的定位**：是「衔接论文 / bridging paper」（把母框架的推导桥接到具体唯象），还是「独立完整理论」（自己推导核心对象）。

误判定位会直接扭曲评分。案例：中微子 V65 是 SL(6,C) 系列三论文中的**衔接论文**，SL(6,C) 几何/谱对象/共同作用量的推导在母框架 CGICE V10 和 V21 里。第一轮把它当「独立理论」审 → **4.4/10 REJECT**（核心批评是「SL(6,C) 装饰性」「桥接定理是重言式」——这些对衔接论文是误判，因为母框架职责不在 V65）。第二轮正确定位为「衔接论文」→ **6.9 → 7.5/10 MINOR REVISION**（同样的稿件，评分差 3 分）。

## 衔接论文的审稿核心四问（替代「是否独立推导」）

1. **衔接正确性**：是否正确引用母框架的谱隙/排除准则/作用量，而非错误重新推导或把母框架结论包装成自己的
2. **独有增量充分性**：衔接论文自己的增量（案例中是有限温热力学 + 味谱 + Module 22）是否构成独立贡献
3. **分工清晰性**：读者能否一眼看出「哪些来自母框架、哪些是本文增量」（接口字典、归属声明、转录标注）
4. **诚实度**：是否诚实标注「外部输入 vs 自推导」「衔接 vs 独有」

## 衔接论文的 P0 类型（与独立论文本质不同）

衔接论文的阻断级问题几乎全部是**「衔接显式性」**层面的写作/结构缺陷，而非物理推导错误：

- **接口字典缺失**：母框架的排除准则（如 G₀≤y²W/(M²Δ)）→ 本文的判据（如 a_X−κJ_Λ3）之间的映射（a_X↔G₀⁻¹、C₃↔C_Λ）从未显式写出
- **引用编号混用**：同一 `[4]` 同时指向母框架 A 和母框架 B
- **逻辑未闭合**：母框架「零温排除」与本文「有限温临界温度」看似矛盾的兼容条件未说明
- **摘要/标题未声明 bridging 定位**（读起来像独立论文）
- **转录身份未标注**：从母框架转录的定理没标 `[transcribed from X, Thm Y.Z]`
- **节首缺归属声明**（"本节复现 CGICE，仅 G1-G5 是新 EFT 输入"）

## 摘要重写的前置步骤：数值预测校核

按顶刊要求重写摘要前，先用 Python **独立复算**所有关键数值预测（质量、Σ、劈裂比、候选斜率），确认与正文一致（误差 <10⁻⁸ 级），再注入摘要。案例：M_R=5.69×10¹³ GeV、Σ=0.0616 eV、R=0.03985 全部独立复算通过后才写进摘要。摘要须含：定位声明（bridging）、精确数值（非"near 0.06 eV"）、味谱独立假设声明（"a new input, not a consequence"）、诚实边界（PMNS/δ_CP 未定、失败是"transparent compatibility failure not a fit"）。

## 魔鬼代言人的「诚实化最后一公里」三问（衔接论文必被挑战）

1. 摘要的「forward prediction」实为「conditional numerical evaluation at a specified parameter point」？（参数未被实验固定时，"forward" 措辞偏强）
2. 候选斜率是「独立假设」还是「知道数据约束后的事后选择」（post-hoc selection）？主假设被否证后保留两个通过的后验候选 = "falsification theater"
3. 衔接论文是否产生「母框架无法单独产生的、可证伪的正面预言」？若增量只是条件 EFT 自洽演化 + 被否证的假设，价值退化为「母框架数值后处理」

这三个挑战与诚实度定位一致，是「诚实降级」的延续，不是方向转变。
