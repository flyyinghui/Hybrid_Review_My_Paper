# Reviewer Calibration Audit — 审稿人分级一致性审计

审计对象不是论文，而是**审稿人本身**：量化 5 代理 Hybrid Review 产出的 P0/P1/P2/P3 分级是否稳定可靠。用途：(a) 决定是否值得用快模型（JevAny/RLCR）做分级初筛；(b) 给审稿流程做质量背书。

## 一、Hybrid Review 报告的结构模式（提取发现的先决知识）

扫 163 份审稿 md 后确认的格式规律：

- **V64 5agent Round 系列是最规范格式**：每个审稿人（R0_EditorInChief / R1_FormalVerification / ...）有独立 `#### P0 (blocking)` / `#### P1 (major)` / `#### P2 (minor)` / `#### P3 (optional)` 小节，发现条目为 `**P1-A (new, §...):** 描述`。
- **发现的 ID 跨轮不稳定**（对齐时的最大坑）：
  - R1 = 自由文本（`- [§位置] 描述`，无编号）
  - R2 = 字母编号（P0-A/B/C, P1-A..D, P2-A..F）
  - R3/R4 = 数字+字母混合（P1-1, P0-A...）
- **5 个审稿人各自独立命名** → 同一个 ID 字符串（如 `P1-A`）在不同审稿人那里是**不同的发现**。不能按 ID 字符串对齐，必须按语义/描述文本对齐。
- **只有 P0 有正式的 resolution table**（`| **P0-1** (...) | **FIXED** | ...`）。P1/P2/P3 没有逐条 resolution，只有非正式跨轮标记（`still` / `Round 3 flagged this` / `only partially closed`）。
- 正则提取陷阱：发现标题的括号内容常含**嵌套括号**（`**P1-A (new, §2 eq. (3) and §3.2):**`），`\([^)]*\)` 会在内层 `)` 处截断。用宽松匹配 `\*\*P[1-3]-([A-Za-z0-9]+)\*\*[^:\n]{0,70}[:：]\s*(.{0,110})` 并排除表格行（`| **P1-1**` 开头）。

## 二、审计指标（V64 三轮实测，2026-10-03）

数据：R2 标记的 8 个 P0（3 字母 + 5 数字）在 R3 被 5 审稿人逐个做 resolution → 40 个「发现×审稿人×状态」三元组。

| 指标 | 结果 |
|---|---|
| **P0 误报率** | **0%**（8 个 P0 全部被 5 审稿人确认为真问题，无一反悔） |
| P0-C 修复状态一致率 | 100%（5/5 FIXED） |
| P0-A 修复状态一致率 | 80%（4 FIXED + 1 PARTIALLY，R1 发现 55 vs 51 def 计数差） |
| P0-B 修复状态一致率 | 60%（3 PARTIALLY + 2 REMAINS） |
| P0-1~5 数字编号一致率 | 100%（全 CONFIRMED FIXED） |

## 三、P1/P2/P3 跨轮漂移（R3→R4）

- **漂移单向：只降级、零升级**。R3 的 P1 到 R4 几乎全降 P2，无 P2→P1、无 P1→P0。
- **降级驱动 = 论文改进**，不是审稿人噪声（论文加了诚实标注/部分修复 → 严重度真实下降）。
- **核心逻辑问题焊死不动**：§5→§5.1 经典括号 vs 紧致相位量子化 gap，三轮始终 P1，打补丁也不降级。

## 四、关键洞察（训练快模型分级器必读）

**同一发现文本，跨轮会被标不同 P 级——因为「论文版本」变了，不是发现变了。**

例：`Esteban 2020 引用过时` 在 R3 是 P1、R4 是 P2。若直接拿「发现文本 → P级」当训练对，同一输入会得到矛盾标签，训练崩。

**正确做法**：训练 JevAny/RLCR 分级器时，`state` 不能只放发现描述，必须含**论文当前版本快照**（这轮改了哪些、引用什么版本、加了什么诚实标注）。JevAny 的 `state` 字段本就是「共享状态」，正好承载这个。

## 五、JevAny/RLCR 采纳结论

- **P0 档不值得上快模型**：LLM 已 0% 误报，且 P0 漏判即灾难。
- **Jev 价值在 P2/P3 批量初筛 + 去重**：数量大（P1=146/P2=120/P3=65），大量 P2/P3 是「可选建议」，LLM 深审是浪费。
- 角色偏差是隐变量：R1_FormalVerification 系统性更严格（唯一标 PARTIALLY/REMAINS 的）。

## 六、历史标注数据盘点（训练 Jev 的原料）

483 个 md 文件 → **463 条结构化发现**（粗体编号+分级）：P0=105 / P1=146 / P2=120 / P3=65 / C=27。最大来源 V64 5agent Round2/3/4 = 216 条。作 baseline 分级器够起步，作生产级不够（标签是 LLM 自评非人工 gold label；需 2000+ 条且用跨轮一致性筛高置信子集）。
