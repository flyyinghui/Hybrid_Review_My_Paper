# 公式序号重排：字母后缀乱序 → 连续编号（2026-09-26 V64 验证）

## 场景

审稿意见整合时向既有章节插入新子节（§3.1、§4.1、§5.1），新子节的公式常被赋予
字母后缀编号（`\tag{9a}`/`\tag{9b}`/`\tag{9c}`、`\tag{12a}`/`\tag{12b}`/`\tag{12c}`），
导致与主序列乱序：
- `9a/9b/9c` 出现在 `(10)(11)` **之后**（因为 §3.1 插在 §3 主体之后）
- `12a/12b/12c` 出现在 `(13)` **之后**（因为 §4.1 插在 §4 的 (13) 之后）
- 读者交叉引用时编号与位置对不上，审稿人（consistency 代理）会报 P0/P1

## 检测

```bash
grep -nE '\\tag\{[0-9]+[a-z]\}' paper.md   # 找出所有字母后缀公式
# 再对比其行号与主序列：若 9a 的行号 > 10/11 的行号，即乱序
```

## 修复：按出现顺序连续重排

1. **提取 `\tag` 出现顺序**，建立 `旧编号 → 新连续编号` 映射（按行序 1..N）。
2. **先替换 `\tag{X}`**（每个 `\tag{...}` 唯一，直接 `re.sub` 带映射回调）：
   ```python
   import re
   tag_map = {'1':'1', ..., '9a':'12','9b':'13','9c':'14','12':'15','13':'16','12a':'17', ...}
   content = re.sub(r'\\tag\{([^}]+)\}', lambda m: '\\tag{'+tag_map.get(m.group(1),m.group(1))+'}', content)
   ```
3. **再替换正文引用**——⚠️ 必须用**带上下文的精确字符串替换**，绝不能全局正则
   `\((\d+[a-c]?)\)`。原因：圆括号数字在物理论文里大量出现且都不是公式引用：
   - 群符号：`SL(6,C)`、`SU(6)`、`SU(2)`、`U(1)`、`su(3)`、`S(U(3)×U(2)×U(1))`
   - 年份：参考文献 `(1973)` `(2010)` `(1958)` `(2014)`
   - 函数值：`P(0)`、`Q(0)`
   - 范围引用：`(6)–(11)`、`(20)–(21)`（两边都要分别命中）
   
   做法：对每一处需要改的正文引用，用足够长的唯一子串锚定，如
   `("within the domain of (15)", "within the domain of (21)")`、
   `("Equation (19a) implies", "Equation (27) implies")`。
   每处替换前 `assert old in content` 确认命中，脚本末尾打印 miss 清单。

## 验证（三查）

```bash
# 1. 无残留字母后缀引用（应为空）
grep -oE '\([0-9]+[a-c]\)' paper.md | grep -v 'tag'
# 2. 群符号未被误伤（应有非零计数）
grep -c 'SL(6' paper.md; grep -c 'SU(6)' paper.md; grep -c 'U(1)' paper.md
# 3. \tag 连续编号完整
grep -oE '\\tag\{[0-9]+\}' paper.md | sort -V   # 应为 1..N 无重复无缺
```

## 附带结论

- 一次重排（V64）涉及 36 个公式：`\tag` 替换 + ~14 处正文引用精确替换，全部命中即
  `missed` 列表为空。
- 重排后**重新编译 Lean 不必要**（只改 md 正文，不动 .lean 的定理名），但若论文头部/§10
  声称了公式总数，需同步核对。
- 若后续还要插入新公式，优先用连续编号而非字母后缀，可避免再次乱序；字母后缀只在
  "紧邻父公式的派生子式"（如 `(19a)`/`(19b)` 是 (19) 的推导步骤）时语义才成立。
