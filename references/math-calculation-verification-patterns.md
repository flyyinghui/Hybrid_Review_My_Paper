# 论文数学计算结论独立审查 — 错误模式速查（CGICE V9.1 案例）

> 场景触发：用户要求"对所有具体数学计算结论是否准确给出评审"。
> 方法 = 逐条提取论文所有数值/推导结论 → Python 精确计算 + 手工代数推导独立重算 → 与论文声称值比对。
> 关键区分：**"由定义推出来的数"（恒等式，如 τ=6π/35、α 倒数、ln 值）通常对；"用来支撑物理论断的数"（预测值）是错误高发区。**

## 五类可复用错误模式（按出现频率）

### 1. 维度 vs 标度指数混淆
- 案例：N_e = (70/6)ln(1+10⁶)=161，但论文自己的体积公式 Vol∝(2E/λ₁)³⁵（指数是 35）。
- 根因：把相空间维数 dim(T*M)=70 误当体积的能量标度指数（70 维谐振子相空间体积 ∝ E^{70/2}=E³⁵）。
- 正确：N_e = (35/6)·ln(1+10⁶) ≈ **80.6**。
- 检查法：任何"从体积公式算 N_e/熵/配分函数"处，核对公式里的 E 指数 vs 计算里用的乘性因子是否一致。

### 2. RG 方程与解不自洽（因子 2）
- 案例：方程写 dg/dlnμ = b₀g³/8π²，解却写 g = g₀/sqrt(1 − b₀g₀²/(8π²)ln(μ/M))。
- 根因：分离变量 ∫dg/g³ = −1/(2g²) 带来 1/2，故解的分母应是 **4π²** 非 8π²（解实际对应 dg/dlnμ = b₀g³/16π²）。
- 检查法：把论文给的解代回方程求导验证 d(g²)/dlnμ = 2g·dg/dlnμ，若差因子 2 即方程与解不自洽。

### 3. Landau 极点符号错误
- 案例：μ_Landau = M·exp(−8π²/(b₀g₀²)) ≈ 10⁴ GeV（红外方向），但解形式分母 1 − (b₀g₀²/8π²)ln(μ/M) 的零点在 ln(μ/M) = **+**8π²/(b₀g₀²)（紫外方向）。
- 检查法：极点位置 = 让解的根号分母为零，符号由 ln(μ/M) 的系数决定，不要凭"强耦合在红外"的物理直觉写 exp 符号。

### 4. 内积归一化依赖量（|ρ|² 类）
- 案例：SU(6) Weyl 矢量 |ρ|² 在标准 trace-form 约定 Tr(XY) 下 = **35/2 = 17.5**；在 2× 归一化 B=2Tr 下 = **35**。
- 结论：35 与 35/2 不矛盾，是同一"因子 2 归一化"的两面。论文必须显式声明归一化，否则按标准约定复核就是因子 2 错误。
- 完整速查：`physics-proof-engine/references/rho-squared-normalization-cheatsheet.md`。

### 5. 临界标度公式缺因子
- 案例：μ_crit = M·exp(−(8π²/g₀)(1−1/g_crit)) 缺少 1/b₀ 因子，且临界条件形式（1−1/g_crit）错误。
- 正确：μ_crit = M·exp(−(8π²/(b₀g₀²))(1−g₀²/g_crit²))。

## 归一化声明落地（三文件同步，改声明不改数值）

当审查发现"归一化/约定未声明"问题时，处理 = **加显式声明，不改数值**（这样保留 λ₁=35/3 全链条自洽）：

1. **MD**：改 § 正文句 + 引用块（如 "λ distinction" 块），声明"采用 2× 归一化 B=2Tr，标准约定下为 35/2"。
2. **DOCX**：python-docx run 级操作。⚠️ 数学符号（λ₁、|ρ|²、35/3 等）部分是普通文本 run、部分是 OMML 公式——`para.text` 拿不到 OMML 内容（显示为空），只有普通文本 run 能通过 `para.text`/`run.text` 读到。用 `run.text.replace(old, new)` 改普通 run + `para.add_run(...)` 段末追加声明，OMML 公式原样保留不破坏。
3. **Lean**：在 axiom 上方注释块加 `NORMALIZATION CONVENTION` 块（纯注释，0 语法影响，0 sorry 不变）。
4. 先备份 `.bak_xxx`；DOCX 保存到 /tmp（ext4）再回写 NTFS；回写后 reopen 验证段落数不变。

## 评审报告"问题解决后调整"模式

当论文修复了评审发现的某 P0 后，评审报告对应条目从"🔴 错误"改为"✅ 已解决"，并**同步更新四处**：
- 总评（错误数 N→N−1，P0 数相应减）
- 该 P0 条目本体（保留"原判定"+"处理方式"+"结论"，附更深层遗留问题如"λ₁=35/3 仍非自然几何量"归入 P1）
- 修复优先级表（该行打删除线标 ✅）
- 一句话结论（"5 个核心数值全错"→"4 个有错 + |ρ|² 已声明解决"）
