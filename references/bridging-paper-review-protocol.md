# 多论文系列「衔接论文」审稿协议（2026-10-14 V65 案例）

## 核心教训
多论文系列（母框架 + 衔接论文）审稿前，**必须先识别每篇论文的定位**。把衔接论文误当独立理论审，会系统性误判——因为母框架的推导被当作衔接论文"缺失的推导"来扣分。

## 案例：V65 中微子（同一篇论文，两种定位，评分差 3.1 分）
- 误当独立理论审：**4.4/10 REJECT**（核心批评："SL(6,C) 装饰性""桥接定理是定义重言式"）
- 当衔接论文审：**7.5/10 MINOR REVISION**（14 项 P0 全是衔接显式性问题，无物理错误）

差异根源：SL(6,C) 几何、谱对象分离（35/29）、共同作用量 A(φ)=Z−γφ²/2 都是母框架（CGICE V10 / V21）的推导，不是衔接论文（V65）的职责。误判 = 把「未独立推导母框架内容」当缺陷扣分。

## 三论文分工图景（审稿前提，必须注入 prompt）

| 论文 | 定位 | 完整推导（自有） | 对衔接论文的接口 |
|---|---|---|---|
| CGICE V10 | 母框架① | 几何信息动力学四方程组、谱对象分离、光速、λ_KLS、熵闭合 | §7.9 中性凝聚排除检验 |
| V21 三大时空相 | 母框架② | 六维→四维条件约化、共同作用量、三阶段宇宙学 | §5 内部电荷/输运 |
| V65 中微子 | **衔接论文** | 有限温热力学 + 味谱 + Module 22（独有增量） | Module 21 转录 CGICE 深化定理链 |

## 审稿问题转向（关键）
从「是否独立推导 X」→ 四个维度：
1. **衔接正确性**：是否正确引用母框架，而非错误重推或错误包装母框架结论为自己结论？
2. **独有增量充分性**：独有推导（热力学、味谱）是否构成一篇独立论文的充分贡献？
3. **分工清晰性**：读者能否一眼看出哪些是母框架、哪些是增量？
4. **诚实度**：是否诚实标注「外部输入 vs 自推导」「衔接 vs 独有」？

## 衔接论文的典型 P0 缺陷（审稿时重点排查）
- **接口字典缺失**：母框架 → 衔接论文的映射（如 a_X↔G₀⁻¹、C₃↔C_Λ）未显式写出
- **引用编号混用**：一个编号 [4] 同时指向两个母框架（CGICE 和 V21）
- **逻辑未闭合**：母框架的零温结论 vs 衔接论文的有限温结论的兼容条件缺失
- **转录身份未标注**：转录的定理（Module 21）被当作原创，未逐条标 [transcribed from X]

## 落地检查表（衔接论文审稿后）
- [ ] 摘要首句声明 bridging 定位（"This paper bridges... [母框架①] and [母框架②]"）
- [ ] §1 增量三分：(i) Bridging increment (ii) Original increment (iii) Independent hypothesis
- [ ] 母框架内容章节节首加 Attribution 声明（"本节复现 [母框架]，仅 X 是新输入"）
- [ ] 接口章节显式写出映射字典 + 逻辑闭合（零温 vs 有限温兼容条件）
- [ ] 转录模块逐条标注来源；独立假设标注"not a consequence of the parent program"
- [ ] 摘要数值预测与正文一致（独立复算校核）

## 魔鬼代言人的典型挑战（衔接论文的核心弱点）
即使 4 个审稿人判"无 P0"，魔鬼代言人通常会挑战：
- **P0：M_R 是"输入参数重命名"而非"前向预测"** → "forward" 应改 "conditional forward evaluation at a specified parameter point" + 给误差带
- **P0：候选参数是"事后选择"** → 主假设被否证后保留两个事后拟合的通过候选 = "falsification theater"；需披露枚举空间或给先验选择原则
- **P0：衔接论文缺"独立可证伪预言"** → 若增量不能产生母框架无法单独产生的可证伪预言，价值退化为"数值后处理"
