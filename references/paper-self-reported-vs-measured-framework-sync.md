# Paper Self-Reported Stats vs Measured Active Declarations + Framework Sync

**触发**：把多篇共享母框架的论文（如 SL(6,C) 四论文系列）整合/同步到统一框架文档时，需要把框架文档里的 Lean 统计表（axiom/theorem/lemma/行数/密度）对齐到各论文最新状态。

## 核心教训（2026-09-11 四论文框架同步验证）

**论文自报的 Lean 统计 ≠ 实测活跃声明数**。三处实测差异：

| 论文 | 论文自报 | 实测活跃声明 | 差异根因 |
|---|---|---|---|
| GW-V19 | 48 axiom + 25 lemma | 47 axiom + 22 lemma | 论文用 grep 原始计数（含注释内弃用声明） |
| V17 时空 | 65 axiom + 42 theorem | 62 axiom + 48 theorem | 论文"活跃声明"口径含未落地的重分类提案 |
| CGICE v10 | 99 theorem (2026-09-07 checkpoint) | 109 theorem | checkpoint 之后文件又加了 10 个 theorem |

**判定原则**：以**实测活跃声明**（正确剥离注释后）为唯一权威基准——框架文档本身声明了"活跃声明数"口径。论文自报值可能是 grep 原始计数、旧 checkpoint、或未落地到文件的提案。同一论文内部还可能自相矛盾（V17 L1174 说 42 theorem、L1179 说 36 theorem——笔误，以出现最多者为准）。

## 精确计数脚本（必须含装饰器前缀）

计数 axiom/theorem/lemma 时正则必须带可选装饰器前缀，否则漏掉 `@[...] axiom foo`：

```python
ident = r'[A-Za-z0-9_ΔρλτθμνπσφψΩΣΛΞΓ]+'
decl = r'^\s*(?:@\[[^\]]*\]\s*)?'
ax = len(re.findall(decl + r'axiom\s+' + ident, code, re.M))
```

案例：GW-V19 裸 `^\s*axiom` 漏掉 2 个 `@[honest_axiom]` 装饰的 axiom（46→48），lemma 漏 3 个（22→25）。

注释剥离必须正确处理**嵌套块注释**（见 `lean-nested-block-comment-sorry-pitfall.md`），否则注释内的 "0 sorry"/"48 axiom" 字样污染计数——这是"论文自报 vs 实测"差异的另一个来源。

## 框架同步工作流（版本漂移 + 精确替换）

1. **读框架文档现有统计表**——通常有**两处**要同步（§审计摘要表 + §形式化质量评估表），别只改一处。
2. **读每篇论文最新自报统计**：grep `axiom|theorem|lemma|\.lean|formal|证据链` 且含数字的行。
3. **独立实测每个 Lean 文件**（正确注释剥离 + 装饰器前缀），得到权威数字。
4. **对账分三类**：
   - 版本漂移（用户给的文件名版本号高于框架，如 `paper_triple_gw_v19.md` vs 框架 GW-V17）→ 更新
   - 复核一致（实测 == 框架现有值）→ 不动，明确说"无需改"
   - 口径差异（论文自报 ≠ 实测）→ 以实测为准
5. **精确字符串替换，禁止全局裸数字替换**——`48`/`24`/`62`/`59` 等裸数字出现在大量无关上下文（`(1+z)^3≈148`、`√3`、`35/3`、`H₀=67.42`）。必须用带表头/单元格上下文的**整行锚定**：
   ```
   "| 定理数 | 48 | 109 | 53 | 59 |" → "| 定理数 | 48 | 109 | 59 | 88 |"
   ```
   版本号类（`GW-V17`→`GW-V19`、`triple_gw_dm_proof_v17`→`v19`）是唯一标识可安全全局替换；但"三峰引力波 V17"（无 GW- 前缀）要单独处理。
6. **替换后验证**：grep 旧值确认 0 残留 + 确认新值出现。
7. **密度列随行数重算**：`定理密度 = theorem / (行数/100)`。行数 3,606→3,751 时定理密度 1.47→1.57，不能只改分子不改分母。

## 常见版本漂移信号（提前预判要更新的点）

- 用户给的文件名版本号高于框架里的版本 → 框架落后（GW-V17→V19）
- 框架表格 theorem 数 < 实测 → 新增了定理（V63 53→59 因新增 6 条 CW/KL 证据链定理）
- 证据链 theorem 数（21→29）与主文件 theorem 数（80→88）要**分别追踪**，两个独立计数
- "真实推导"列也随新定理变（V63 `1 (seesaw_suppression)` → `7 (...+6 CW/KL 定理)`）
