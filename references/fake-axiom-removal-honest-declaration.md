# 假公理删除 → 诚实声明 → 形式化可行性方案（终审后的修复闭环）

> 场景：终审发现 Lean 证明含假公理/零内容公理，需要（1）删除它们，（2）补诚实声明，（3）生成"供后续严格证明"的形式化可行性方案。
> 验证于 CGICE V9.1 论文（`cgice_proof_v9.lean`，删 4 条公理 66→62）。

## 一、假公理三类型（终审审计必查）

| 类型 | 特征 | 检测 | 危害 |
|---|---|---|---|
| **假命题公理** | `∀ x, P(x)` 但 P 有反例 | 取反例实例化（如 `∀ grad_sq lapV, 0 ≤ grad_sq−lapV` 取 0,1 得 0≤−1）| 爆炸原理，可证任意命题 |
| **假实数等式公理** | `Real.exp/sqrt 常数 = 精确值` 但不等 | Python 独立算 `math.exp(-280.7)` vs `10^-122`（差 1.24 倍）| norm_num 盲区，exp 等式可假 |
| **零内容公理** | `(1:ℝ)*(1:ℝ)=(1:ℝ)` 或 `(1:ℝ)=(1:ℝ)` | 读公理体，是平凡恒等式却命名深刻 | 表演性声明，冒充形式化 |

**关键启发**：`norm_num` 对 `Real.exp`/`Real.sqrt` 透明性不足，无法察觉 `exp(-280.7) = 10⁻¹²²` 这类假等式。假实数等式公理比 `sorry` 更糟（sorry 是"未完成"，假公理是"可证 False"）。

## 二、删除前的「孤立公理」验证（决定是否影响编译）

删除任何 axiom 前，先 grep 确认它是**孤立的**（仅声明、零引用）：

```bash
grep -n "axiom_name" proof.lean
# 只出现 1 次（定义处）= 孤立公理，删除不影响编译和其余定理
# 出现 ≥2 次 = 被引用，删除会破坏编译，需先处理下游
```

CGICE 案例：4 条假/零公理各自只出现 1 次（`covariance_dissipation_value` 后面的 `lambda_CC_relaxation_nonzero` 定理用的是 `Real.exp_ne_zero` 而非该公理），删除后 23 theorem + 13 lemma 全部不受影响。

## 三、删除 + 补诚实声明（正确模式）

删除后**不要留空**，补注释声明「研究级前提 / 未形式化 + 指向形式化方案」：

```lean
-- [2026-08-19 删除假公理] 原 axiom spec_gap_bound 已删除:
--   原形式 ∀ grad_sq lapV, 0 ≤ grad_sq - lapV 是假命题 (取 0,1 得 0≤-1), 可证 False。
--   半经典势阱条件仅对特定 V_eff 成立, 非全称。
--   该条件在 Lean 中未形式化 (研究级前提)。形式化可行性方案见: CGICE_Formalization_Roadmap_1_SpectralGap.md
```

诚实声明的三要素：①删除原因（假命题/假等式/零内容的具体反例）②真实数学状态（研究级前提，未形式化）③指向后续方案文件。

## 四、生成形式化可行性方案（3 文件模板）

对每个「未形式化」的论述，生成独立方案文件，结构固定：

1. **目标定理精确陈述**——拆成多步论证链（不能整体打包）
2. **已形式化 vs 未形式化**——逐步骤标注
3. **Mathlib 基础设施盘点**——列出每个所需设施的状态（✅有/⚠️部分/❌无）
4. **分级可行性**：✅完全可形式化（代数/算术）→ ⚠️部分（需降级为 honest-axiom）→ ❌不可（需研究级前提 + 文献引用）
5. **诚实替代方案**——降级定位（如"代数上严格证明了 |ρ|²=35，谱论证引用 Harish-Chandra"）
6. **建议的 Lean 骨架**——可执行的诚实版本

**核心判断模式**（CGICE 三个方案验证）：

| 论述 | 可形式化性 | 定位 |
|---|---|---|
| 谱隙数值（\|ρ\|²=35 的 A₅ 根系 + FdV）| ✅ 完全 | 代数，可发表 |
| 谱隙谱理论（为什么是谱下界）| ❌ 不可 | 研究级前提，引 Helgason 2000 |
| 122 量级解码 | ⚠️ 数值恒等不需公理 | "重参数化"非"解码" |
| EEM 随机展开 | ❌ 不可（无随机分析）| 研究级前提，引 Elworthy 1982 |

## 五、删除后的诚实性权衡（关键教训）

删除假/零公理会**暴露论文「形式化证明」的虚假完整性**：
- 删除前：66 axiom「看起来」形式化完整，但含假公理（可证 False）
- 删除后：62 axiom「诚实」，但暴露谱理论/122 解码/EEM 从未真正形式化

**这不是退步**——用「更短但真实的公理清单」换「更长但含假公理的清单」是净改进。论文必须在「形式化范围」声明里明确标注哪些论述是研究级前提，而非让假公理假装覆盖。
