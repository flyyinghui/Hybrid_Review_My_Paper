# 审稿代理「因子/量纲/漏项」重算的误判模式与人工核验协议

**适用场景**：5-agent 终审（venue-fit 五代理）中，technical / lean_specialist 代理声称发现「因子 2 / 因子 a² / 量纲不匹配 / 漏项 / 比例方向写反」等**硬算术错误**时。

**核心教训**：代理对物理约定（共形时间 vs 物理时间、Itô vs Stratonovich 随机解释、傅里叶空间 vs 坐标空间量纲、振荡平均因子）的理解不一致，会产生**系统性误判**。任何代理声称的「硬算术错误」，在采纳并让作者改论文之前，**必须由人工沿源项推导链独立重算一遍**。

## 四类误判模式（2026-10-17 三峰引力波 V20 第二轮 technical 全部命中 3 类）

### 1. 共形时间 vs 物理时间（源项差 a² 因子）

- 论文里 `h''`（共形时间导数，`d/dη`）与 `ḧ`（物理时间导数，`d/dt`）是不同方程，源项差一个 `a²` 因子。
- 转换：`h' = a ḣ`，`h'' = a² ḧ + a ȧ ḣ`，`k = a K`（共形 wavenumber k → 物理 wavenumber K）。除以 a² 后，源项 `(2a²/M²)Π` → `(2/M²)Π`。
- **误判案例**：代理用共形时间方程 (6.3) 的源项 `(2a²/M²)Π^{TT}` 代入 `Π^{TT}=FGd²/(2a²)` 得 `FGd²/M²`，声称论文 (6.6) 的 `S₀=F0G0d²/(M²a*²)` 多因子 `1/a*²`。实际 (6.6) 是物理时间方程（`ḧ`），源项应为 `(2/M²)Π = FGd²/(M²a²)`，论文正确。
- **核验要点**：确认方程用的是 `h''` 还是 `ḧ`、是共形 k 还是物理 K=k/a，再代入源项。

### 2. Itô vs Stratonovich 随机解释（修正项是否抵消）

- 随机扩散矩方程中，Itô 修正项（`d(ζ⁴)=4ζ³dζ+6ζ²(dζ)²` 的 `6ζ²·2D` 项）与低阶矩方程里的噪声项，在**一致的随机解释**下会**恰好抵消**，导致最终结果不含噪声项。
- **误判案例**：代理声称 `κ̇₄ = -24qC³ - 12DC`（论文漏 `-12DC`），实际是 Itô/Stratonovich **混用**：Itô 下四阶矩方程含 `+12DC`，与 `-6CĊ` 里的 `-12DC`（来自 Ċ 的 `2D` 项）抵消，得 `κ̇₄=-24qC³`；Stratonovich 下同样得 `-24qC³`。
- **核验要点**：检查代理是否把 Itô 修正项与 Stratonovich 的低阶矩噪声项混用。一致的随机解释下，噪声项应抵消。

### 3. 振荡平均 ½ 因子遗漏

- `cos K(t-s)cos K(t-s')` 的振荡平均 = `½ cos K(s-s')`（`cos a cos b = ½[cos(a-b)+cos(a+b)]`，`cos(a+b)` 项平均掉）。
- **误判案例**：代理声称 (7.13) 少因子 2，实际是它漏了论文明写的 `\overline{cos·cos}=½cos` 因子。代入后 (7.13) 恰好正确。
- **核验要点**：检查代理的积分推导是否包含振荡平均的 `½` 因子。

### 4. 傅里叶空间 vs 坐标空间量纲

- 应力协方差 `C_Π` 定义 `⟨Π(k)Π(k')⟩=(2π)³δ³(k-k')C_Π` 里，`Π(k)` 是**傅里叶空间**量，量纲与坐标空间 `Π(x)` 差傅里叶变换的量纲（`∫d³x` 量纲 3）。
- **核验要点**：量纲分析前先确认 `Π` 是 k 空间还是坐标空间，`δ³` 的量纲（-3），以及 `C_sp` 是 `C_Π` 的哪个部分（空间部分 vs 完整 UETC）。

## 人工核验协议（代理声称硬错误时必做）

1. **锁定源项推导链**：从 Π 定义 → 场方程（注明共形/物理时间）→ 源项 → 解的完整链条，逐式重算，不跳步。
2. **核对三个约定**：① 共形 vs 物理时间（`h''` vs `ḧ`，`k` vs `K`）；② Itô vs Stratonovich（修正项是否抵消）；③ 振荡平均 `½` / 傅里叶量纲。
3. **交叉验证**：同一代理在不同轮次对同一式的判断若不一致（如第一轮说「因子一致」、第二轮说「少因子 2」），即提示该点是代理重算不稳定，必须人工重算，不能直接采信。
4. **记录误判**：把代理误判的式子 + 正确推导 + 误判根源写成一条，避免未来轮次再次被误导。
