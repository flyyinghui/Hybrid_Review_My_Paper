# Comparative Two-Version Paper Review

## Trigger
"对比两个版本" / "compare two versions" / "V{N} vs V{M}"

## Protocol
When comparing two versions of the same paper (e.g., expanded vs condensed, or old vs new):

### Agent Configuration
5 agents, each comparing BOTH versions on a single axis:
1. **EIC**: Overall assessment, publication venue recommendation
2. **Logic/Structure**: Which has better narrative flow, fewer gaps?
3. **Mathematics**: Which has more rigorous derivations?
4. **Verifiability**: Which makes more falsifiable claims?
5. **Devil's Advocate**: Strongest arguments against each

### Scoring
Each agent scores BOTH versions (0-10) on their axis.
The version with the higher score may differ by axis — this is EXPECTED.
- Expanded versions often score higher on math (more honest)
- Condensed versions often score higher on logic (clearer narrative)

### Output
- Per-axis scores + winner
- EIC recommendation on which version to submit
- Action items: what to transplant from the losing version to the winning version

## Case Study: 6D Spacetime V11 vs PRD (2026-07-26)
- V11 (100K chars, 6.2MB): higher math score (6 vs 4), more honest
- PRD (30K chars, 338KB): higher logic score (8.5 vs 6.5), clearer narrative
- EIC: submit PRD, transplant V11's honesty declarations
- Result: PRD V12 Fused scored 2.6/10 (progressive honesty paradox)

## Cosmology Benchmarking
When reviewing cosmology theory papers, benchmark against:
- Lambda-CDM (6 parameters, χ²/DOF~1)
- Early Dark Energy (EDE)
- Modified gravity (Horndeski/DHOST, f(R))
- Primordial black hole DM

Key questions:
- Does the theory outperform Lambda-CDM on any metric?
- Does it resolve the Hubble tension (H₀ discrepancy)?
- Are predictions testable with current/near-future experiments?
