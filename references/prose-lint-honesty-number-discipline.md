# prose-lint 诚实性 tells（B6）+ 数字纪律（N）— BootLoops 移植

> 来源：BootLoops `prose-lint`（Matthew D. Schwartz）E 段 + N 段。落地为 `ars-awa-hybrid-review` 规则组 B6 + 规则组 N。
> 定位：B6 补句子级/数字呈现级的诚实性 tell；N 补数字呈现的机械矛盾。

---

## 一、B6 — 诚实性 tells 六条（integrity，不是 style）

> 规则组 B1–B5 聚焦公理/引用/校准层面的诚实性。B6 补**句子级/数字呈现级**。逐条 grep，命中即记录，不用眼扫。

| # | tell | 判据 | 修复 |
|---|---|---|---|
| B6.1 | **捏造精确性** | 编数字/计数/日期当数据 | 只用有真实来源的量；估计显式标"估计"或删；宁要更小但已核实的 claim |
| B6.2 | **重要性通胀** | 声称"被需要"/"比实际更重要" | 只声称真实："at the frontier of what is computable"，非"what the field needs" |
| B6.3 | **出处错误** | 错标谁构建/撰写/发现 | 对照真实 repo/论文核验，不靠记忆 |
| B6.4 | **结果过度声称** | partial/未验证 round up 成"done" | 报告真实状态；绝不暗示通过了没通过的检查 |
| B6.5 | **自信模糊** | 有争议/近似事实（"a first"/记录/日期）平铺直叙 | 要么 pin 来源，要么精确 hedge，绝不模糊 |
| B6.6 | **封闭区间/引号完整性** | 见下方三子项 | 见下 |

**B6.6 三子项（最易漏）**：
- (a) **认证区间向外舍入**：下端点向下、上端点向上；认证下界只能向下舍。
- (b) **引号需逐字收据**：fair paraphrase 加引号 = 出处错误。
- (c) **error-bound/residual 摘要只能保守方向舍**：1.06×10⁻⁷ 的 agreement **不是** "10⁻⁷"；trace 每个数量级摘要回源值并查舍入方向。

## 二、N — 数字纪律十三条

> 核心原则：**每个数字出现在多个表面（正文/表格/图注/图标签/摘要），每一对表面都是一个静默矛盾位点。** 这些是机械类矛盾，sweep 它们，不信任眼睛。与规则组 C 互补——C 抓"值变了没同步"，N 抓"值没变但呈现方式制造了矛盾"。

| # | 名称 | 判据 |
|---|---|---|
| N1 | **舍入方向** | 测量数字/精度计数**绝不向上舍**——实测 23.85 位打印 23 非 24；achievement 数字永远朝更弱 claim 舍 |
| N2 | **减法一致呈现** | 读者会相减的数字必须一致舍入——41.2 和 3.9 支持"37 位 gap"；独立 floor 成 41、3 后打印算术为假（38）。分解和同理：舍入列必须重组出舍入总和 |
| N3 | **每个 N/N 带单位** | "812/812 exact"——条目/列/行/成员？计数名词来自不同表面则错，直到对照源定义核对 |
| N4 | **显示平局** | 值落在舍入平局（141/400=0.3525）在 float（35.2）与 half-up（35.3）打印不同→生成标签与正文静默分歧。显示标签从整数计数用精确 half-up 十进制算术算，绝不从 float |
| N5 | **二代舍入** | 已舍入值的比/差（0.172/0.126→1.37）≠ 未舍入计算（1.362）。逐字引源记录值；绝不"纠正"可引用记录。z-score 不能从显示输入重算可能是从未舍入值精确算的——说明哪个约定 |
| N6 | **分解不求和→命名边界** | 打印部分凑不齐打印总和，通常是一次分析里两个不同边界（按日期切的窗口/按不同方案赋标签），不是过期数字。找到边界错配并说明，不 nudge 数字逼和 |
| N7 | **非嵌套分母** | 两过滤器差一个 NET 计数（4201 kept vs 4178 kept，overlap 3900）："23 fewer"真，"23 removed"假。写子集从句前先查嵌套 |
| N8 | **反直觉方向数字带机制从句** | 正确数字朝"错"方向动（样本翻倍功率反降）读作 typo。核实后每处打印附半句机制 |
| N9 | **两个真数字一个假括号** | 两统计共享一个括号（"p=0.005；高于均值十五个标准差"）诱导合成两都不支持的 claim。各自命名 provenance 或分开 |
| N10 | **情态词是数字的一部分** | "can be 1.08×" 压缩成 "is 1.08×" 把可能性变判定。压缩/重述 claim 时查情态（can-be/is/must-be）与查数字同样仔细 |
| N11 | **一符号一对象** | 同一字母一节作系数、一节作曲/矩阵/半径误导读者。改名较廉价实例并 sweep。词同理：技术义+普通义同段出现→首次 gloss 或改名 |
| N12 | **claim-bearing 连接散文** | 关系从句静默附加可核查事实（"their best-fit model carries 的趋势"）——一致性 pass 必须覆盖数字周围连接散文，不只数字 |
| N13 | **标识符完整性双向** | 看似正确可能错、看似错可能对——注册机构迁移前缀，陌生前缀 DOI 可能是真的、"canonical" 形式反而失效。归一化前必须 resolve 两个候选；奇数者获胜留 dated do-not-fix 注释。裸整数在应引用的位置可能是 \citealp misfire（"(cf. 9)"） |

## 三、执行顺序（prose-lint G 段 scrub 程序）

1. **朗读，逐句**——flag 任何像营销/chatbot/新闻稿的句子。
2. **先跑 parse/composition pass（F）**，再 grep 词汇（A）+结构（B），再跑 agentless-prose greps 作独立 pass。
3. **查开头结尾**——首句、每个小标题、每段末句，最密藏身处。
4. **把摘要当只读它的人读**——任何无 antecedents 的内部名都是 tell（论文自言自语）。
5. **口述文本不豁免**——作者素描是内容规格，不是成品散文，照常渲染+lint。
6. **lint the linter's output**——修复是新散文、再生 tells。重写句子的人不能是最后复审它的人：用不同眼睛扫每次 fix pass 的 DIFF。
7. **诚实 pass（E）与数字 pass（N）分开、且优先级最高**——核验每个数字/名字/日期/归因；在渲染文本上跑跨表面检查（body vs table vs caption vs figure label）。
8. **root-cause 每个外部抓到**——读者 flag 一句过了本技能的句子时，做两处编辑：治句子 + 把 pattern 加到本目录（用抓到的句子作 type specimen）。
8b. **核实再"修复"**——finding 是假设不是裁决。两处同值可恰巧都正确；odd 标识符可能是真的（N13）；源注释可 stale。Freeze 任何无法核实的数字而非"改进"。
8c. **尊重引用与生成材料**——编辑前定位所有逐字引用 span；生成表/图/图注在 GENERATOR 里治并重生成，绝不手改输出。
9. **ship-critical 文本的不动点循环**：lint→fix→fresh-lint 直到 fresh pass 零 finding。finding 引用具名规则（无 taste-only finding）；prior deliberate cures 保护免重样式；fixer 逐字替换绝不 re-flow。绝不报"linted to stability"作质量 claim——不动点只认证你跑的 sweep 找不出更多；报告检查了什么。

**终测**：*一个没耐心忍受机器腔散文的敏锐人类编辑，会对这里任何一句皱眉吗？* 会，就没完。

## 四、执行要点（移植后适配）

- B6 与 N 是**机械 sweep**，优先 grep 不靠眼扫。典型 grep 目标：`can be` vs `is`（N10）、`~` 近似号、`≈` vs `=`（结合规则组 A3）、`exact`/`precisely` 计数（N1/N3）、带括号的双统计（N9）。
- B6/N 的 finding 并入 Finding Output Format，`[类别]` 字段用 `B6` 或 `N`，severity 参照规则组 D：N 类多为 P2/P3（呈现矛盾），但若导致结论矛盾（N2 假算术、N10 情态把可能变判定）升级 P1；B6.6 封闭区间舍入方向错、B6.4 结果过度声称 → P1/P0。
- **不要**用 B6/N 替代规则组 B1–B5 和 C——它们是正交补强，不是替换。
