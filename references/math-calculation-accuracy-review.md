# 数学计算结论准确性专项评审 (Math-Calculation-Accuracy Review)

**触发词**： "对所有具体数学计算结论是否准确给出评审" / "数学计算结论准确性" / "数值是否算对" / "verify all numerical/calculation conclusions" / "具体数学计算结论"

## 何时用

当用户要求评审一篇论文中"**具体数学计算结论是否准确**"时——这是与一致性/逻辑/数学严密性评审**不同**的专项模式。不是评论文叙事、不是审公理自洽，而是**逐条把论文里的每个数字/公式结论重新独立算一遍**。

## 方法论（四步）

1. **提取全部数值结论**：通读全文（含正文、附录、表格、以及 Lean 证明文件里的数值断言/注释），列出每一个"带有推导链或声称来源的数字"——N_e、τ、λ、g_TC、μ_crit、比值、幂次、Weyl 矢量范数、Betti 数、RG 解、相空间体积等。**不遗漏表格和 Lean 注释里的数值断言**（Lean 注释常藏有论文正文没写的 ansatz，如 `w(a) = -1-2εa⁻³`）。

2. **独立重算（两条独立通道）**：
   - Python 精确计算（`execute_code`，math/comb 等 stdlib）——每个数值算到足够精度，打印"独立重算值 vs 论文声称值"。
   - 手工代数推导——特别针对"**公式与公式之间**"的关系（如 RG 方程 vs 其解、体积公式 vs 标度指数、积分公式 vs 声称结果）。这一步抓的是"方程和解不自洽"这类纯数值验证抓不到的错。

3. **分类判定**（本模式的核心产出结构，四类）：
   - ✅ 纯算术正确项（定义性算术：由符号定义直接推出来的数）
   - 🔴 P0 计算错误（数值本身错，且承载物理论断）
   - 🟠 P1 内部不一致（两个声称互相矛盾 / 量纲错 / 循环论证 / 反推值）
   - 🟡 P2 陈述/结构问题（命名混淆、未声明的 ansatz、符号冲突）

4. **区分"计算错误" vs "内部不一致"**：如果论文两个公式互相矛盾（方程 vs 解、公式 vs 用公式算出的数），那是**计算错误**；如果数值来源不透明/等于某个观测值（循环），那是**内部不一致**。

## 核心元洞察（多次验证）

**"由定义推出来的数"几乎全对；"用来支撑物理论断的数"几乎都有错。**
一篇理论物理论文的 τ=2π/λ、α 倒数关系、纯代数恒等式、ln 值、幂次展开通常是对的；而 N_e、g_TC 流、Landau 极点、μ_crit、|ρ|²、H₀t₀ 这类"用计算支撑预测"的数值是错误密集区。评审火力集中在第二类——它们是审稿人复算会立刻抓包的地方。

## 可复用的错误模式清单（CGICE V9.1 案例，9 类）

1. **因子 2 错误（方程 vs 解不自洽）**：RG 方程 dg/dlnμ = b₀g³/8π² 的解分母应写 **4π²** 而非 8π²。验证：对论文的方程独立分离变量积分，对照论文给出的解。
2. **符号错误（极点/临界位置）**：Landau 极点 exp(-…) 应为 exp(+…)，导致极点从红外挪到紫外、物理叙事反转。验证：把论文的解代入，看分母零点落在哪个方向。
3. **维数 vs 标度指数混淆**：相空间体积 ∝ E³⁵（70 维谐振子 ∝ E^{70/2}=E³⁵），但 N_e 计算误用**维数 70** 作指数 → N_e 翻倍（80.6 vs 161）。验证：检查 N_e 因子用的到底是"相空间维数"还是"体积的 E 指数"。
4. **Weyl 矢量范数归一化**：SU(N) 的 |ρ|² = N(N²−1)/12（标准约定）。SU(6) = **35/2 = 17.5**，不是 35。35 需非标准归一化 B=2n·Tr 且须显式声明。检测：直接展开 ρ=(5/2,3/2,1/2,−1/2,−3/2,−5/2) 平方求和。
5. **量纲错误**：Λ_CC ∝ λ_⊥·M_Pl² 是 [M]²，但宇宙学常数（能量密度）是 [M]⁴，缺 M_Pl² 因子。比例式里标 "O(1) 因子" 若实际需 ~10⁻¹²²，则"解决量级鸿沟"是空话。
6. **多项式系数/Betti 数**：P(t)=(1+t²)⁵(1+t⁴)⁵ 的系数是**卷积**，b₄ = C(5,2)+C(5,1) = 15，不能只取 (1+t²)⁵ 的 C(5,k)。验证：`coeff(deg) = Σ_{k,j: 2k+4j=deg} C(5,k)C(5,j)`。
7. **循环校准链**："5.00→5.47 由 0.46% 嬗变推导"——但 5.47/5.00 = 1.094(+9.4%)，0.46% 嬗变只能给 5.02。5.47 是观测值输入（Ω_c/Ω_b），不是输出。检测：检查"推导结果"是否其实等于某个已知观测值。
   ⚠ **2026-09-04 更正**：此条曾把摘要歧义句（"5.00 evolves to 5.47: 0.46% of baryonic matter..."）读成"0.46% 嬗变驱动 5.00→5.47"。独立重算发现 0.46% 属于**另一条独立链** `0.46% × (1+z_eff)³ ≈ 0.68 ≈ Ω_DE`（自洽），与 5.00→5.47（黑洞嬗变）无关。真实缺陷是摘要冒号把两条链拼接的**写作清晰度问题（P1），非算术错误（P0）**。详见 `reviewer-arithmetic-false-positive-verification.md`。
8. **反推值 vs 声称输入**：H₀t₀ = 0.9497 与 Ω_DE = 0.682 不自洽（正确 0.9484）。检测：把论文声称的输入参数代入论文自己的公式，看能否复现声称的输出；复现不了就是反推/校准值。
9. **Casimir 命名**：C₂(伴随) = 2N = 12 对 **SU(6)** 正确，但标 "SL(6,C)" 是命名混淆（半单非紧实形式无此约定）。
10. **频率↔温度换算混淆（把频率比当温度比）**：论文声称 f₁=4.5×10¹¹ Hz 的等效温度 "3.44K=1.26×T_CMB"，但独立算 T=hf/k_B=(6.626e-34×4.5e11)/(1.381e-23)=**21.6K**（非 3.44K），温度比=21.6/2.7255=**7.92×**（非 1.26×）。根因：1.26× 是**频率比**（4.5e11/3.57e11=T₀/ħ 恒等式频率的比值），被错当成**温度比**。检测：凡论文声称某 GW 频率的"等效温度/温度比"，独立算 T=hf/k_B 并对比 T_CMB，检查频率比是否被误标为温度比。三峰 GW V17 案例：f₁ 频率比 1.26 正确，但"3.44K=1.26×T_CMB"的等效温度表述是双重错误（温度 21.6K 非 3.44K，比值 7.92 非 1.26）。

## 与其他评审模式的关系

- 与 `lean-arithmetic-audit-patterns.md`（Lean **内**算术审计）互补：本模式覆盖**论文正文**的数值结论，Lean 审计覆盖**形式化文件**的算术。
- 与一致性评审的区别：一致性看"两个地方是否说同一件事"；本模式看"每个数算没算对 + 有没有独立推导"。
- 与 `proof-paper-cross-ref-revision/references/independent-math-verification-protocol.md` 呼应：那里是**公式级**独立重推导，这里是**数值级**独立重算。

## 交付格式

报告分六节：①总评（评分 + 一句话）②纯算术正确项表 ③P0 计算错误（红）④P1 内部不一致（橙）⑤P2 陈述问题（黄）⑥修复优先级。**所有数值必须注明"独立重算值 vs 论文声称值"**，并明确每一类错误的根因（因子 2 / 符号 / 维数混淆 / 归一化 / 量纲）。
