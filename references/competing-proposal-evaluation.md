# 竞争性修改建议对比评价 (Competing-Proposal Comparative Evaluation)

**触发**：用户给出两份（或多份）对同一手稿的修改建议/审稿意见，要求「哪份更有优势 / 从 N 个维度评价 / 给出融合修改意见」。案例：中微子凝聚 V63 的《V64修改意见》(激进重构派) vs《V64_Reconstruction_Review》(严格条件派)，2026-09-25。

## 核心判断：先识别两份提案的「性质」，再比内容

两份提案往往不是「同一问题不同答案」，而是**性质根本不同**，直接并排打分会误判：

| 典型角色 | 特征 | 常见陷阱 |
|---|---|---|
| **激进重构派** | 把孤立公理「升级为推导」，引入新结构(WindingCharge/诱导引力/Monge传输)，宣称 `[S]` 闭合 0 sorry | 用「更精致的反向工程」掩盖循环论证；`[S]` 是文本计数非编译 |
| **严格条件派** | 断言推不出无条件结论，只建条件性弱命题 + 反例 | 正确但可能过于保守，需吸收对手的正确数值纠错 |

**判据核心 = 证据层级诚实性**：`[S]` 是否真编译闭、所谓「推导」是否实为循环校准、范畴错误是否被抓住。`honest-axiom` 标签**不把假设变结论**——它是注释不是属性，标记为诚实的公设仍是公设。

## 三维度评价框架（用户明确要求的三个维度）

1. **数学基础完备性**：量纲分析、群论归一化、表示论、微分形式次数。
2. **物理定理推导严密性**：所谓「第一性原理推导」是否有独立输入、循环是否真正切断。
3. **物理学阐释自洽性**：范畴错误（生成元混同、对称性误用、单态反常）。

## 决定性技术检查清单 (Category-Error Check Kit)

以下每条都能一击致命，用于快速定位哪份提案在数学/物理上更站得住：

1. **Noether 荷范畴错误**：时间平移的 Noether 荷是**能量**，不是电荷。「时间的共轭动量=电荷」是生成元混同。若坚持「时间荷」命名，须先证明能量生成元与某内部 U(1) 荷的动力学锁定。
2. **对称度量不能产生箭头**：Wasserstein 距离 W(μ,ν)=W(ν,μ) 对称，**不可能**产生时间箭头；熵耗散 ∂_t KL ≤ 0 给的是统计方向非时空方向。
3. **SM 单态无规范反常**：右手中微子若为标准模型单态，「时间荷」U(1)_T 的 ABJ 反常系数取决于完整场内容，不能写死为 g_TC²/8π²。
4. **诱导引力系数符号**：Sakharov 热核展开给出 `G⁻¹ ∝ (1/6 − ξ_conf) M_R² ln(Λ²/M_R²)`，系数在**共形耦合 ξ_conf=1/6 处为零、ξ>1/6 变号**——诱导引力项符号不确定，激进派常只字不提。
5. **CW 系数是超迹非计数**：CW 的 B 系数 = Σ g_s⁴ + 3Σ g_V⁴ − 2Σ y_f⁴，**由耦合值决定**，非纯群论计数；「105 > 30 故 B>0」是错的（费米子项为负）。
6. **A/B = λ_⊥ − 1/2 是匹配输入**：CW 嬗变 `v_Σ = M_U e^{−35/6}` 仍含校准输入，循环论证只是被「更精致的反向工程」掩盖，未真正切断。
7. **定义混淆普朗克质量**：`M_R := sqrt(G⁻¹)` 把重中微子质量定义成了普朗克质量——直接 grep `def.*sqrt.*GravitationalCouplingInverse` 或类似定义即可命中。
8. **反例构造是决定性否定判据**：静态凝聚真空（有质量无时间荷）、反向相位运动（CP 共轭支）、同参数改 M̄_P 改 G——三个构造性反例不可推翻。

## 融合输出模板（用户偏好「融合」而非二选一）

1. **脊柱** = 严格条件派的诚实框架（条件相位-荷对应 + 证据分级 + 反例 + 验收标准）。
2. **补丁** = 激进派的**正确数值纠错与可复用形式化引理**（seesaw 秩定理、0νββ 三角不等式上界、DM 10^9 因子、PBH 质量反向、声波频率、cw_excess_eq_klFun KL 映射）。
3. **降格** = 把「对偶已证明」降为「条件相位-荷对应」；把「第一性原理推导」降为「维度自洽的条件匹配」。

输出结构：①总判定（两份性质不同）②三维度对比表 ③谁更有优势（逐维度）④融合意见（脊柱+补丁+降格）⑤我补充的专家级修正（能量vs电荷 / 诱导引力符号 / 单态反常）。

## 关键陷阱

- **不要只总结两份建议**——要加自己的独立技术判断。本案例的增量价值在于：能量非电荷、共形耦合符号、单态反常三点两份建议都未充分展开。
- **先 grep 验证声称再下结论**：`grep -cE '^\s*axiom\b'` / `^\s*theorem\b` 拿活跃声明实数，`grep -n 'sorry'` 逐行看上下文（注释内 sorry 是假阳性）。本案例确认 `axiom timecharge_nuR_duality : G_inv = c_nuR * (nuR_cond)^2` 是对偶性**直接公设**（非定理），`T_SEESAW_MASS_NONCIRCULAR` 把 M_R 定义成 sqrt(G⁻¹)=普朗克质量。
- **维数 −4 系数**：`[G⁻¹]=2` 而 `[⟨N_R†N_R⟩²]=6`，对偶恒等式必须含维数 −4 的系数；激进派常漏。
