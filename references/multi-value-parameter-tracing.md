# Multi-Value Parameter Tracing — 多值常数溯源技术

**来源**：四论文联合审查（CGICE V9.1 / 时空 V17 / 中微子 V63 / 三峰 V16，2026-08-29）。
审查中发现同一耦合常数 g_TC 跨论文出现 4 个互斥值，独立重算后彻底解开其根源。

## 技术：当一个物理常数出现多个值时，反推每个值依赖的另一个参数

**症状**：同一理论系列的多篇论文/同一论文多章节中，核心常数出现多个互斥值，
表面看是"作者笔误"，实际往往是**不同参数选择的必然结果**——暴露了隐藏的循环定义
或未统一的框架分支。

**方法**（三步）：
1. **提取所有取值**：grep 每篇论文/每个章节的该常数所有出现处（注意 LaTeX 变体
   `g_TC`、`g_{TC}`、`g_TC²`、`g_TC^2` 都要命中）。
2. **反推依赖参数**：对每个值，代入该常数参与的定义式，反解出它隐含的另一个参数。
   案例：g_TC 四个值全部来自 D1 对偶 `g_TC² = 8π²/λ_KLS`——
   - `g_TC=2.60` ⟺ λ_KLS=35/3（g_TC²=8π²/(35/3)=24π²/35≈6.77）
   - `g_TC=1.50` ⟺ λ_KLS=35（g_TC²=8π²/35≈2.26）
   - `g_TC=2.83` ⟺ g_TC²=8（无 λ_KLS 对应，独立假设）
   - `g_TC=0.5` ⟺ 无任何数学来源（纯唯象输入）
3. **判定循环定义**：若每个 g_TC 值都由 λ_KLS 决定、而 λ_KLS 本身又可能由 g_TC 定义，
   则 D1 对偶是**循环论证**（g_TC 与 λ_KLS 互为定义）。修复方向：让 λ_KLS 有独立来源
   （如 Harish-Chandra 谱几何），或让 g_TC 由独立物理过程（散射截面）确定。

## 连带发现（同一审查中暴露的数学错误）

1. **|ρ|² 归一化分裂**：SU(6) Weyl 向量 ρ=(5/2,3/2,1/2,-1/2,-3/2,-5/2)，
   标准 Killing 归一化 |ρ|² = 70/4 = **17.5**；要得 35 必须改用根长²=2 归一化。
   论文用 35 却未声明归一化约定 → 谱隙数值物理意义存疑。
2. **λ_KLS=35/3 是数学错误**：SL(6,C)/SU(3,3) 是非紧实形式，Witten Laplacian 谱**连续**、
   无正谱隙；KLS 定理要求紧致流形。35/3 是把紧致对偶 SU(6)/SO(6) 的谱几何未经证明移植到
   非紧空间。正确值 λ_KLS=35（紧致对偶）或承认谱隙不存在。
3. **实形式不统一**：V17 用非紧 SU(3,3)，其余三篇用紧致 SU(6)——同 35 维但拓扑不同，
   谱几何性质完全不同，必须统一。

## 通用原则

跨论文/多版本一致性审查时，**先做"常数取值-反推依赖"矩阵**（8 轴：g_TC / λ_KLS / DM机制 /
H₀ / 实形式 / 维度 / 质量谱 / GW谱），比逐篇独立评审更能暴露框架级矛盾。同一常数多值
不是笔误，是框架分叉的信号。
