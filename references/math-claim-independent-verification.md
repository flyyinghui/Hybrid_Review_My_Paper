## 二、循环论证 / 反向工程检测（4 判据）

理论物理论文声称"从第一性原理推导出观测值 X"时，按以下判据排查是否只是把 X 反推成参数：

1. **参数 = 观测值反推**：检查关键参数是否是"让公式恰好等于观测值"的解。
   例：ΔR≈4.01，精确反解 `122·ln10/(2·35) = 4.0131`——ΔR 被调成恰好产生 10⁻¹²²。任何量级都能靠改 ΔR"解码"。
2. **循环公理对**：A 由 B 反推，B 又由 A 反推。
   例：`η = 12·(2.60)²/(4π²) = 2.055`（η 由 g*=2.60 反推），`g_star_value : √(4π²·η/12) = 2.60`（代入 η 定义后退化为平凡恒等式 √6.76=2.60）。g*=2.60 是硬编码输入，FRG 从未真正计算 η_k。
3. **表演性声明**：真命题的名字暗示未证明的结论。
   例：`theorem no_free_parameter : (35/3)·10⁻¹²² ≠ 0 := by norm_num`——只证"非零数乘积非零"的平凡事实，名字却叫"无自由参数"。
4. **零内容公理**：后件恒真的蕴含式伪装成物理声明。
   例：`axiom witten_spectrum_nonneg : ∀x, 0≤x → True`——`0≤x→True` 对任意 x 恒真，零信息量。

## 三、假实数等式公理检测（Lean norm_num 盲区）

`axiom f(x) = 数值` 这类公理，Lean 的 norm_num **无法验证含 exp/sqrt/π 的实数等式**（Real 常数不透明）。作者可能把假等式写成公理而不被编译器察觉。

- 例：`axiom jacobian_value : exp(−2·√35·4.01) = 10⁻¹²²`——真实值 `exp(−47.45) = 2.48×10⁻²¹`，**假了 101 个数量级**。
- **检测**：用 Python 重算每条"数值断言公理"声称的等式。
- **严重性**：一条假公理 = 爆炸原理 = 整份形式化证明可证任意命题（**比 sorry 更糟**，因为 sorry 至少诚实）。
- **附加**：检查公理参数是否张冠李戴——CGICE 论文正文用 |ρ|²=35、Lean 用 |ρ|=√35，却都声称结果 =10⁻¹²²（把 |ρ|² 误当 |ρ|，错在不同位置）。

## 五、|ρ|² 归一化速查
