# 参考文献机器核验（投稿前）

> 来源：三大时空相 V18 第四轮复审（2026-09-19）。31 条文献，核验出 0 幻影 / 0 孤儿，但正则首次运行
> 误报 1 幻影（[100]）+ 5 孤儿（[1]-[5]），根因是两类正则盲区，修正后全清。可复用脚本模式。

## 两类正则盲区（必踩）

1. **数学区间被当成文献引用**：正文 `κ ∈ [10,100] from unitarity bounds` 中的 `[10,100]` 是
   κ 取值范围，不是引用 [10] 与 [100]。正则 `\[(\d+)(?:\s*,\s*(\d+))?\]` 会误提 [100] → 幻影引用。
   **修正**：检查 `[` 前一个字符，若是 `∈`/`∉`/`=`/数字（如 `κ ∈ [10,100]`、`x ∈ [0,1]`），跳过。
   ⚠️ 注意 `∈` 与 `[` 之间常有空格（`∈ [10,100]`），前字符是空格而非 `∈`，需往前看 1-2 个字符或
   直接 grep 全文人工确认 `[数字,数字]` 是否真是引用。

2. **双横线范围引用 `[1--5]`**：正文用 `[1--5]`（两个连字符）表示 [1][2][3][4][5]，而正则若只匹配
   单横线 `[-–—]`，会漏掉 → 把 [1]-[5] 误判为孤儿引用。**修正**：范围分隔符用 `[-–—]{1,2}`（1-2 个横线），
   命中 `[1--5]` 时展开为 [1..5] 全部加入 cited 集合。

## 核验脚本要点

```python
ref_listed = set(int(m.group(1)) for m in re.finditer(r'^\[(\d+)\]\s', refs_section, flags=re.M))
cite_re = re.compile(r'\[(\d+)(?:\s*[-–—]{1,2}\s*(\d+))?(?:\s*,\s*(\d+))?\]')
# 遍历 body，检查 [ 前字符排除数学区间；范围 [N--M] 展开；[N,M] 加两个
phantom = sorted(cited - ref_listed)   # 正文引但列表无
orphan  = sorted(ref_listed - cited)   # 列表有但正文未引
```

- 列表编号连续性：`list(range(1, max+1)) == sorted(ref_listed)`。
- 结论判据：phantom=0 且 orphan=0 且连续 → 通过。任何 phantom 都是 P0（幻影引用），orphan 是 P2。

## 已知边界

- 参考文献用 FULL 标准格式（author, title, journal, volume, page, year）时 DeepSeek 翻译会保留英文；
  仅 loose/incomplete 条目（裸 "Book title (publisher, year)"）的标题会被翻译成中文——cosmetic，提示用户
  是否要回退标题为英文以保持引用格式一致。
- 正文 `κ ∈ [10,100]` 这类数学区间是**唯一**容易误报的形态；`[a,b]` 区间、`[0,1]` 归一化等同理。
