## 2. 公式序号重排：字母后缀 → 连续编号（乱序修复）

审稿意见整合插入新子节后，公式常出现字母后缀乱序（§3.1 的 `9a/9b/9c` 插在 `10/11`
之后、§4.1 的 `12a/12b/12c` 插在 `13` 之后）。修复=按出现顺序全量重排为连续编号：

1. **建立映射**：按 `\tag` 出现顺序，把每个旧编号（含字母后缀）映射到连续整数。
   `9a→12, 9b→13, 9c→14, 12→15, 13→16, 12a→17, 12b→18, 12c→19, 14→20, ...`
2. **先换 `\tag`**：`re.sub(r'\\tag\{([^}]+)\}', callback, ...)` 查映射表，`\tag{9a}`→`\tag{12}`。
3. **再换正文引用**：必须用**精确上下文字符串替换**，禁止全局正则 `\((\d+[a-c]?)\)`
   ——会误伤群符号 `SL(6)`/`SU(6)`/`U(1)`/`su(2)`/`su(3)`、参考文献年份 `(1973)`、函数值
   `P(0)`/`Q(0)`。每个引用带足够上下文（如 `"from (12b) alone"`→`"from (18) alone"`）。
4. **验证**：`\tag` 序列 == `1..N` 连续；grep 残留字母后缀 `\([0-9]+[a-c]\)` 应为空；
   群符号计数不变（`SL(6)`/`SU(6)`/`U(1)` 的 grep -c 与源一致）。

V64 案例：36 公式重排为连续 (1)-(36)，14 处正文引用精确同步，群符号零误伤。

## 3. 转换表算术错误：多审稿人独立抓到的真实 bug 需独立验证

第三轮审稿人给 §5.1 加的三归一化转换表抓到一个**真实算术错误**：`3(B−L)` 列 N_R 行
写 `−3/2`，但 `3(B−L)=3q_{B_6}=3×(−1)=−3`。3 个审稿人（consistency/logic/technical）
独立报同一错误 → 这是强信号，不是误判。

**教训**：新增的「多归一化转换表」这类对照表，必须**逐行独立验算**（每列 = 声明身份
的算术），审稿人抓到后先自己算一遍再修，别直接改表。修复后 grep 整个表逐行核对
`3(B−L)=3×q_{B_6}` 是否全部成立。

对比另一处「restricted-root multiplicity=2 维度不闭合」是**审稿人误判**——审稿人把
A₅ 正根数算成 5，实际 15，`5+15×2=35` 闭合。区分真实 bug vs 误判的唯一方法就是独立
重算（A₅ 正根数 = n(n+1)/2 = 15）。

## 4. md-lean 编译状态一致性：grep 全变体一次改干净

手稿被外部进程扩展后，编译状态表述会分散在 6+ 处残留「未编译」——lean 文件头部
`STATUS: Not compiled in this revision, as requested`、md Abstract、Contributions(v)、
具体定理节 `[Lean proof bodies: ...; not compiled in this revision]`、Module 7 说明
`supplied without compilation`、deferred-audit 注释 `after compiling the file`。

**统一修复**：`grep -niE "compil|not compiled|without compilation|future build|future
validation|Not compiled"` 抓全变体，一次性全改（含 lean 文件的块注释 STATUS 和 Module
说明，改注释不影响编译但需重编译验证 `EXIT_CODE=0`）。日期同步更新（compiled 26
September 2026）。

## 5. Lake 编译的 `/.local/bin/env` 噪音是无害的

`lake env lean` 后台编译时 stdout 出现 `bash: /.local/bin/env: No such file or directory`
（×2）——这是 lake 内部某子 shell HOME 为空时的环境探测噪音，**编译仍成功**
（日志 EXIT_CODE=0，`#print axioms` 输出齐全）。判据：看日志文件内容而非 stderr 噪音；
`EXIT_CODE=0` + `#print axioms` 全绿 = 编译通过。不要因这条噪音误判编译失败或反复重试。
（注意：`export HOME=/root` 需在命令开头，但即使设了，lake 内部嵌套 shell 仍可能报这条
无害噪音。）
