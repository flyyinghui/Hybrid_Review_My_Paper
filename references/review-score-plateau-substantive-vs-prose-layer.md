# 终审评分持平的层判定：表述层 vs 实质层

> 来源：2026-10-13 CGICE V10 四轮 5-agent 终审。文字层 P0 连续清零，但评分连续持平。

## 模式

同一论文多轮 5-agent 终审后，评分连续持平（如 CGICE V10 三轮：consistency 7.5 / technical 8.4 / logic 8.2 / lean_specialist 6.5，CQG 恒为 MAJOR REVISION）。此时**不要继续文字迭代**，先判定瓶颈属于哪一层。

## 两层瓶颈

| 层 | 特征 | 文字修复是否有效 |
|---|---|---|
| **表述层** | 摘要防火墙、overclaim 措辞（"yields"/"closes"/"derives" vs [M]/[A] 边界）、定理名暗示推导、边界标注不完整 | ✅ 有效，分钟级可提升 |
| **实质层** | 净预测度 ≈ 0、实质物理定理 = 0、缺少真实动力学工作包、核心常数是 [M] 输入而非推导 | ❌ 无效，需要真正物理/数学工作 |

## 判定信号

- lean_specialist 明确说「形式化层是诚实的，但不是实质的」「303 theorem 中实质物理定理 = 0」→ 实质层。
- publication_strategist 明确说「净预测度 ≈ 0，无新预言」→ 实质层。
- 三个 agent 同时指向**同一处摘要措辞** → 表述层（值得修）。
- 评分理由里「−1.5 定义重言式」「−1 实质占比未量化」但结论句「已诚实标注」→ 表述层已到顶，剩余是实质层。

## 案例（CGICE V10）

- 第四轮：落地 8 个文字层 P0（摘要防火墙、§2.7「two routes→two arithmetic realizations」、§4.4 标题、§5 总括映射、D1 def 体公开）。
- 第五轮：评分持平（7.5/8.4/8.2/6.5），lean_specialist 判定「实质物理定理 = 0」，publication_strategist 判定「净预测度 ≈ 0」。
- **结论**：文字层 P0 已清零，评分不再随文字迭代上升；瓶颈是实质层（一个真实动力学工作包 + excess covariance→stress energy 显式映射），需真正的物理工作，非审稿迭代可解决。

## 行动准则

1. 多轮评分持平时，先读 lean_specialist 的「实质 vs 诚实」判定和 publication_strategist 的「净预测度」。
2. 若判定为实质层瓶颈，**停止文字迭代**，诚实告知用户：当前诚实化已到顶，CQG 判定稳定，剩余是实质工作（列出一个具体工作包），不要继续空转文字修复给用户虚假的「进展」。
3. 若判定为表述层瓶颈，继续落地文字 P0（摘要防火墙 + overclaim 措辞 + 定理名降级 + 边界标注），然后**再跑一轮**验证。
