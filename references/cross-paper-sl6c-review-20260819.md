## Fokker-Planck 协方差耗散（替代雅可比截断，修正 101 阶错误）

原雅可比截断 `J = exp(-2|ρ|ΔR)` 犯了范畴错误：把 |ρ|²=35 误代入 |ρ| 位置，真实 |ρ|=√35≈5.916 时 exp(-2√35·4.01)≈2.5×10⁻²¹（差 101 阶）。

**合法修复**：指数里的 35 必须是**谱隙 λ_∥ = |ρ|² = 35**（不是 |ρ|），驱动协方差耗散 A(τ)~A(0)e^{−2λ_∥τ}：
- exp(-2×35×4.01) = exp(-280.7) ≈ 1.2×10⁻¹²² ✓
- τ_c = 4.01 诚实声明为唯象标定（撤回"无自由参数"）

## 公理/定理序号统一（MD ↔ Lean 对应 + 连续）

四论文修改后反复出现公理编号漂移（如 MD 声称 25/14/61 vs Lean 实际 69）。统一步骤：
1. 提取 MD 的 A 编号 + Lean 的 a 编号，找缺口
2. 重编号映射（用 `re.sub` 函数式一次性替换，避免 A16→A7 与 A7→A6 的顺序冲突）
3. Lean 重命名用 `\ba(\d{1,2})(?=[_\s:(])` 模式（a 编号后跟下划线，如 `a16_master_equation`）
4. 编译验证 0 sorry + 更新 MD 计数声明（如 "24 core axioms (A1-A25)" + "66 Lean axiom declarations"）

## DOCX 段落 run 级替换陷阱

python-docx 修改 docx 段落时，文本常被拆成几十个 run（一个 axiom 列表段落可达 47 run，数学符号如 ⊕/ℝ/μ/Δ 各自独立 run）。`run.text.replace()` 只在单个 run 含完整目标串时有效。**修复**：遍历 `p.runs`，找含完整目标子串的 run 替换；找不到时说明目标串跨多个 run，需重组段落文本或改用更小的匹配单元。
